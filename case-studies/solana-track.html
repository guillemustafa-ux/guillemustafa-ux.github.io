The Solana track — four programs, one ladder of DeFi primitives

Not one-off demos: a deliberate progression through Solana's core patterns — unilateral payment → time-locked release → bilateral atomic swap → continuous market — each deployed and exercised for real on devnet, all consumable from a single live console. Coming from EVM, the interesting part is what translates and what doesn't.

War stories (native Windows, no WSL)

Building this on native Windows surfaced real toolchain bugs — each documented in the repos so the next person loses minutes, not days:

The interleaved IDL

anchor idl build died with EOF while parsing a value. Root cause: the IDL is emitted in fragments by the test harness, and cargo test runs in parallel, so fragments interleave on stdout and the parser receives corrupted JSON. Fix: capture single-threaded (--test-threads=1) and reassemble the fragments with a small Node script — shipped as scripts/build-idl.cjs in each repo.

The silent stack overflow

The AMM's 10-account liquidity instruction blew Solana's 4096-byte stack frame (try_accounts at 4480 bytes) — and cargo-build-sbf printed the error but still emitted the .so with exit code 0. Deploying that is undefined behavior. Fix: Box the Mint/TokenAccount accounts so deserialization goes to the heap. Lesson: check the build log, not the exit code.

Honest testing when the validator won't start

solana-test-validator doesn't run on native Windows (genesis permission failure). The test suites are written — but instead of faking a green run, each README states it plainly and substitutes stronger evidence: real devnet deploys with cited transaction signatures anyone can open in the Explorer.

Constraints as security

Each program leans on Anchor's account constraints as the security boundary: canonical mint ordering enforced at pool creation, has_one tying vaults to their owners, close = returning rent on settlement, bumps stored and reused instead of re-derived, and every arithmetic path in the AMM rounding in the pool's favor with u128 intermediates and explicit overflow errors. Program upgrade keypairs never touch git.

Honesty note: everything runs on Solana devnet (test network, no real value) and is labeled as such. Deployment evidence is cited by transaction signature, verifiable in the public Explorer.
